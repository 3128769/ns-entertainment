# 3.0.4

安装与发布：

- 新增 `install.sh`：一条命令完成安装、更新、备份、回滚和卸载（`--update`、`--backup`、`--rollback`、`--set-password`、`--set-domain`、`--uninstall`）。
- 不会让密码和 Cookie 走明文 HTTP：不绑定域名时用 `https://服务器IP`（自签名证书）；绑定域名时自动申请 Let's Encrypt 证书，申请失败会降级为自签名 HTTPS，而不是明文。80 端口一律跳转到 HTTPS。
- 更新前自动备份（同时复制到安装目录的 `backups/`），更新失败自动回滚到旧版本；也可以手动 `--rollback`。
- `docker-compose.template.yml` 和 README 里的示例固定镜像版本号，不再使用 `latest`。
- CI：增加 `shellcheck`，以及安装脚本的集成测试（新装 → 备份 → 更新 → 更新失败自动回滚 → 手动回滚 → 改密码 → 卸载），另有 nginx / HTTPS 流程的测试。
- 推送 `v*` 标签时，除了构建并发布 amd64 / arm64 镜像，还会自动创建 GitHub Release。

程序本身的行为和数据库结构没有变化（迁移仍是 `0001`），升级和回滚都不需要迁移数据。
