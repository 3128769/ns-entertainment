# 3.0.3

- 新增预构建镜像：打版本标签时，GitHub 会自动构建并发布 `ghcr.io/3128769/ns-entertainment:<版本>`（同时支持 x86_64 和 ARM64）。安装时直接下载镜像，不再需要在自己的服务器上花几分钟构建，也不依赖 npm、PyPI 和 Docker Hub。
- `docker-compose.yml` 的本地构建明确使用 `runtime` 阶段，不再把测试依赖打进镜像（原来 `docker compose build` 构建的是最后一个阶段，即测试镜像）。
- 程序行为、数据库结构（迁移仍是 `0001`）都没有变化，升级和回滚不需要迁移数据。
