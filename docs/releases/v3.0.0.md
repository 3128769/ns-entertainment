# 3.0.0

全面重构。**数据库结构、接口路径和字段、任务与通知的可靠性语义都没有变化**，所以可以随时回滚到 2.0.2；界面外观沿用 2.0 的设计令牌。

## 前端

- 由原生 ES 模块 + 整页 `innerHTML` 重绘，改为 Vue 3 + TypeScript + Vite：状态响应式更新，表单输入、滚动位置和焦点不会因刷新丢失。
- 31KB 层层覆盖的 CSS 合并为一套设计令牌（明暗两套）和组件样式。
- 编辑账号由三套弹窗合并为一个带分页签的弹窗，只提交改动过的字段；各页入口深链到对应分页签。
- 新增：总览顶部“需要处理”（Cookie 过期、签到待核实、监听异常、今天漏签、后台服务未运行）；30 秒自动刷新；左下角后台服务状态；关键词/私信页的行内开关；删除代理/Bot 前提示还有多少账号在用；Bot 编辑时 Token 可留空保持不变。
- 登录令牌与主题沿用旧的本地键，升级后无需重新登录。

## 后端

- 拆掉 `storage.py` 的“读整份快照再 diff 回写”兼容层，任务只提交自己改动过的字段，Cookie 被替换时丢弃旧 Cookie 的结果。
- `operations.py` 按任务拆成 `tasks/checkin.py`、`keywords.py`、`messages.py`、`cookie_check.py`；调度规则抽成纯函数 `domain/schedule.py`；账号校验抽成 `domain/accounts.py`。
- 统一的 `AppError(code)` 和应用级错误处理，API 路由不再逐个 `try/except`；请求体校验改用 `Literal`/正则而不是 `min_length=5` 的取巧写法；校验失败返回稳定的 `{"detail": "VALIDATION_FAILED", "fields": [...]}`。
- 退役一次性的 1.x→2.0 JSON 迁移脚本和根目录的单行兼容 shim；新增 `python -m nsapp.cli migrate`。
- 与线上 2.0.2 的逐项对比：调度计划 3000 个随机用例一致；签到、关键词、私信、掉线检查四类任务在 54 个场景步骤里的返回结果、账号记录、发出的通知和历史记录一致（唯一的有意差异见下）。

## 行为变化（均为修正）

- 关键词监听只读公开 RSS，不再把成功结果当作“Cookie 有效”写回（旧版会让开启了掉线通知的账号状态来回跳）。
- 更新 Cookie 后，清除上一个 Cookie 留下的“已过期”标记。
- 登录限速按客户端地址（nginx 的 `X-Real-IP`）而不是全局，且清理过期的失败记录；新增 `POST /api/auth/logout` 使服务端会话失效；登录时清理过期会话。
- 代理列表的 `assigned_count` 现在是真实的使用数（旧版恒为 0）。
- 时间格式非法时返回 `NODESEEK_SCHEDULE_INVALID`（旧版是笼统的 `REQUEST_FAILED`）。
- `/assets/*` 使用内容哈希并长期缓存，`index.html` 不缓存；API 响应加 `Cache-Control: no-store`。
