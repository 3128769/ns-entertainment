# 3.0.2

- 新增 `python -m nsapp.cli set-admin-password`：在界面之外修改管理员密码（至少 8 位），并让该账号的所有登录会话失效。支持交互输入，也可以用环境变量 `NS_NEW_PASSWORD` 传入。
- `docker-compose.yml` 为两个服务加了日志轮转（每个文件 10MB，保留 3 份），避免容器日志无限增长。
- 去掉 compose 里程序并不读取的 `NS_ROLE` 变量。
- 文档与仓库：补全搭建说明、增加安全说明（`SECURITY.md`）、依赖自动更新配置、MIT 许可证和演示截图（截图使用的是演示假数据）。
